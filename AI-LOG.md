# Лог использования AI

Использовал несколько AI-инструментов по разным задачам:
Codex 5.6 — для помощи с реализацией Block A и тестами.
Claude Opus 5 и Astra 6 — для дополнительного code review и проверки спорных решений.

Предложения AI проверял вручную и не принимал автоматически. Часть идей после проверки была отклонена.

Для Block B сначала сам разобрал PublishController, после чего использовал AI для проверки выводов и помощи с оформлением REVIEW.md.

## Block A

- Использовал AI для декомпозиции задания, обсуждения структуры pivot-миграции `post_tag` и проверки связей many-to-many между `Post` и `Tag`.
- Обращался за помощью с `FormRequest` и обсуждал attach/detach API. После обсуждения выбрал `syncWithoutDetaching` для привязки тегов с сохранением существующих связей и без дублей при повторном запросе.
- Обсуждал загрузку tags. От глобального $with отказался, чтобы не добавлять лишние запросы, и оставил eager loading только для posts.show.
- Использовал AI при подготовке feature-тестов и для дополнительной проверки готового Block A

Предложения AI не принимал автоматически: код и предложения проверялись тестами и отдельными review. Дополнительные ограничения `max` для `tag_ids` обсуждались, но без бизнес-требования не добавлялись. Обсуждалось изменение тестовой БД в `phpunit.xml`; настройки baseline оставлены без изменений.

## Block B

Сначала самостоятельно разобрал проблемы в `PublishController`. Затем использовал AI для проверки уже сформулированных проблем, уточнения последствий и оформления `REVIEW.md`. Выводы сверял с кодом. `PublishController` не изменялся.
